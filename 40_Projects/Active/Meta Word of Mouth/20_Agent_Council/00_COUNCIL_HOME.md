# Meta Word of Mouth — Living Project Council

## Purpose
Persistent project-native agent team. Each role maintains its own current project cognition, learns from evidence and leaves an exact restart point.

## Current truth law
Primary council and agent files describe the present. Chronology belongs in `Runs/`; detailed proof in `Evidence/`.

## Living-agent law
A problem is not fully learned until the role has considered:
```text
root cause -> failure pattern -> triggered rule -> checklist detector -> eval/regression -> future activation
```

## Implementation law

## Restart law
Every active role maintains `NEXT_START.md`. The next context starts there, not from zero.
