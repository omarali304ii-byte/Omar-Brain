# Lesson and Pattern Promotion Ladder

## Level 0 — Observation
One event, not yet generalized.

## Level 1 — Candidate lesson
A plausible reusable statement linked to evidence.

## Level 2 — Validated lesson
The lesson has a verified result and a bounded scope. Default minimum: at least one strong direct evidence chain and no unresolved contradiction.

## Level 3 — Pattern
Transferable guidance repeatedly supported. Default promotion threshold:
- at least 2 distinct projects with successful evidence, or
- at least 3 independent occurrences with strong evidence plus explicit review.

## Level 4 — Standard
A pattern becomes a default rule only after:
- explicit governance approval,
- applicability boundaries,
- trade-offs documented,
- successful application evidence,
- migration/compatibility impact considered.

## Level 5 — Constitution
Only foundational system law. Never auto-promoted by AI.

## Demotion
Patterns/standards can be deprecated when evidence changes. Preserve supersession links.
