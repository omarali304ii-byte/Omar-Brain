# Memory Quality and Revalidation

## Quality signals
- directness of evidence,
- source authority,
- verification result,
- number of independent confirmations,
- number of distinct projects,
- unresolved contradictions,
- age relative to volatility,
- clear applicability boundaries.

## Revalidation triggers
- unstable external API/platform facts,
- library/framework major version change,
- security guidance,
- legal/policy facts,
- a pattern fails in a new context,
- old knowledge has not been exercised for a long time.

## Retrieval ranking
Prefer:
1. current canonical truth,
2. validated evidence,
3. active standards/patterns,
4. recent relevant project records,
5. raw observations,
6. AI inference.

Down-rank deprecated/superseded material.
