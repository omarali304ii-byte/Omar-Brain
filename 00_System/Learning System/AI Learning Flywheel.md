# AI Learning Flywheel

The brain should become more capable because real work produces reusable evidence.

```text
Execute real work
   ↓
Observe result
   ↓
Capture exact evidence/failure
   ↓
Extract candidate lesson
   ↓
Deduplicate against existing memory
   ↓
Validate in reality
   ↓
Reuse in later work
   ↓
Measure success/failure
   ↓
Promote to pattern when repeated
   ↓
Promote to standard only through governance
   ↓
Future agents retrieve stronger guidance
```

## Learning sources
- successful implementations,
- failed attempts,
- repeated bugs,
- architecture reviews,
- user corrections,
- provider/API behavior,
- performance incidents,
- migrations,
- project closeouts.

## Core rule
The brain does not improve because AI writes more. It improves because evidence-backed memory changes future decisions.
