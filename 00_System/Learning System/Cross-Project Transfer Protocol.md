# Cross-Project Transfer Protocol

Before applying a lesson from Project A to Project B:
1. identify the invariant behind the lesson,
2. compare stack/version/domain constraints,
3. identify assumptions,
4. check for contradictory project decisions,
5. apply as a hypothesis unless already validated broadly,
6. verify in Project B,
7. update success/failure counts,
8. promote or narrow scope based on evidence.

Similarity is not proof. Transfer must preserve applicability boundaries.
