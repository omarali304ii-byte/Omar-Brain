# Maintenance and Review System

A large brain survives through garbage collection, truth review, portfolio control, and learning revalidation.

## Daily — 5 to 10 minutes
- capture freely,
- process urgent Inbox,
- update exact next action on active work,
- record meaningful decisions,
- preserve meaningful failure signatures,
- avoid cosmetic reorganization.

## Weekly — 20 to 30 minutes
- Inbox to zero or explicit defer,
- review active project health/phase/next action,
- inspect ready/in-progress/blocked tasks,
- pause projects receiving no real attention,
- review ideas under validation,
- extract candidate lessons from runs,
- check duplicate creation.

## Monthly — 45 to 60 minutes
- review goals and business/career direction,
- inspect red/yellow projects,
- inspect docs-vs-repo drift,
- review low-confidence claims that affect decisions,
- review learning candidates for validation/promotion,
- revalidate volatile technical/external knowledge,
- review AI access policy.

## Quarterly — 60 to 90 minutes
- portfolio WIP audit,
- archive dead projects,
- review architecture standards against real evidence,
- inspect patterns that failed,
- review system change proposals,
- validate backup/restore,
- audit retrieval quality with real questions,
- run brain validator and inspect warnings.

## AI maintenance checks
AI may flag:
- duplicate aliases/titles,
- unresolved project identities,
- active project without next action,
- stale active review,
- missing project packet,
- blocked task without evidence,
- completed claim without evidence,
- deprecated note without replacement,
- contradictory canonical claims,
- uncontrolled metadata,
- denied note in external index,
- lesson promoted without evidence,
- docs/repo drift.

## Anti-perfection rule
Organization must improve execution and recall. Do not spend more time polishing the brain than using it.
