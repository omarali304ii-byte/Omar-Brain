# Real Project Learning Contract

Meaningful project work is incomplete until a learning review occurs.

A run may legitimately produce `NO_REUSABLE_LEARNING`; the review itself is mandatory for significant work.

## Run close requirements
- exact `project_id`
- exact `run_id`
- result and acceptance state
- what changed
- verification/evidence references
- failures and unresolved gaps
- reusable-learning review
- skill evidence when a skill was truly applied
- cross-project implications or explicit none

## Truth boundary
Conversation context can bootstrap a manifest. It cannot satisfy verification or evidence requirements.

## Reference-project extraction
For a project intended to teach future projects, also follow [[Reference Project Extraction Protocol]]. Repo verification is revision-locked and must not be upgraded to runtime verification without new evidence.
