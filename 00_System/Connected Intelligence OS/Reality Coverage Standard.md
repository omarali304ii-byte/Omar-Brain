# Reality Coverage Standard

Brain health measures lived experience, not just folder correctness.

## Reality dimensions
- registered real projects
- projects with verified repository/runtime identity
- projects with real runs
- projects with evidence
- causal chains
- learning candidates from runs
- cross-project validations
- freshness of current project truth

## Hard rule
Zero real runs and zero evidence can never produce a high intelligence/health score, even when structural validation is perfect.

## Imported context
Known project facts from prior work may be registered as `context-import-needs-repo-check`. They improve navigation but do not count as verified experience.
