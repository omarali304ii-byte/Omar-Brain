# Omar Brain v4 Upgrade Report

## Why v4 exists
v3 was strong at organization, project execution, hard web-development standards, and evidence-backed completion. v4 adds the missing runtime intelligence architecture:
- explicit semantic/episodic/procedural memory,
- single-writer durable memory,
- supervisor-led specialist agents,
- hybrid retrieval OS,
- structure-aware derived manifest,
- append-only episodes,
- memory proposal queue,
- capability lazy loading,
- event/state control loop,
- retrieval and agent evaluation,
- measurable brain health,
- CI control cycle.

## Design decision
Obsidian remains canonical human-readable truth. Indexes, vectors, graphs, and traces are derived services and may be rebuilt.
