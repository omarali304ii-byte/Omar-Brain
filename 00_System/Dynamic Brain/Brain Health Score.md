# Brain Health Score

## Principle
The Brain should measure whether it is becoming more useful, not merely larger.

## Dimensions
1. **Structure health** — schema/validator errors, duplicates, orphaned IDs.
2. **Truth health** — stale active notes, contradictions, missing provenance.
3. **Execution health** — active projects with exact next action, blocked age, run recovery.
4. **Retrieval health** — eval Hit@K, stale retrieval rate, context size.
5. **Memory health** — pending proposals, unsupported commits, revalidation backlog.
6. **Learning health** — validated lessons vs candidate clutter; transfer success/failure.
7. **Operational health** — backup/restore, index freshness, automation failures.

## Rule
A single composite score may be displayed, but decisions should inspect the underlying dimensions. Do not hide a critical failure behind a good average.
