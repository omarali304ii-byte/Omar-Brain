# Omar Brain v8 — Skill Graph Upgrade Report

## Scope

Expanded v7 from 21 active skills to **61 active skills** and changed the marketplace from a flat registry into a capability graph with bundles, project-stack detection, candidate development, and evidence capture.

## New control layer

- Skill Graph Standard
- Skill Composition and Handoff Protocol
- Skill Development Lifecycle
- Skill Evidence Ledger
- machine graph, bundles, candidates, evidence ledger
- skill router v2
- project stack detector
- graph/bundle connectivity validator
- candidate proposal CLI
- evidence append CLI

## Anti-bloat decision

A candidate skill is not active. New capability must pass deduplication, provenance, contract design, sandbox plan, and review.

## Source learning

The GitHub Brain catalog was used as a capability mine. Skills were normalized into the local Omar Brain architecture rather than copied as disconnected folders.
