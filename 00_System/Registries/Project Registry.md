# Project Registry

This registry is generated conceptually from canonical notes with `type: project`. Do not duplicate project data here manually.

## Resolution keys
Every project should expose:
- `project_id`,
- canonical title,
- aliases,
- repo URL,
- local path,
- company/product links,
- project class/profile.
