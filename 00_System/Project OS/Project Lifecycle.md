# Project Lifecycle

```text
Idea candidate
   ↓ validation
Validated idea
   ↓ commitment + outcome + done definition
Project active
   ↓
Discovery / foundation / implementation / verification / release
   ↓
Completed only after Done gates
   ↓
Closeout + knowledge extraction
   ↓
Archive
```

## Promotion from idea to project
Requires:
- concrete outcome,
- reason/owner,
- done definition,
- scope boundary,
- initial next action,
- project class/profile.

## Active execution
Every active project maintains:
- current phase,
- health,
- next action,
- queue,
- current state,
- recent run/evidence.

## Completion
`completed` is a verified state, not a mood. Use [[00_System/Project OS/Definition of Done]].

## Closeout
- result vs intended outcome,
- unfinished residual work,
- operational handoff,
- lessons extracted,
- patterns/failures linked,
- successor projects linked,
- active views cleaned.
