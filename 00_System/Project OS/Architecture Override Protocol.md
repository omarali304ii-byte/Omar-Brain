# Architecture Override Protocol

Global standards are defaults, not blind dogma. A project may override them only through an explicit decision/ADR.

## Override must contain
- baseline rule being overridden,
- project-specific constraint,
- alternatives considered,
- chosen deviation,
- consequences,
- risks,
- verification plan,
- revisit trigger.

Convenience, preference, or “AI generated it this way” is not sufficient evidence.
