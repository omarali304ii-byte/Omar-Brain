# Documentation Standard

## Current-state docs
Describe what works now. No fake roadmap completion and no endless history.

## Architecture docs
Explain boundaries, flows, truth sources, invariants, and major trade-offs.

## Decisions
Record meaningful choices separately with rationale and revisit triggers.

## Code comments
Explain why, constraints, and non-obvious behavior; do not narrate obvious syntax.

## AI context
Keep compact context packs derived from authoritative sources. A context pack is a cache, not truth.

## Change rule
Update docs whenever behavior, structure, schema, API, permissions, events, tests, roadmap, or module boundaries materially change.
