# WCAG 2.2 AA Delivery Standard

## Default target
User-facing web targets WCAG 2.2 AA unless explicitly changed.

## Three-layer verification

1. Automated checks
2. Manual keyboard/focus/zoom/reflow
3. Representative assistive-technology checks for critical journeys

## High-risk areas
- custom controls
- dialogs
- menus
- data grids
- drag/drop
- auth
- forms/errors
- dynamic announcements
- charts
- media

Automated scans cannot claim conformance by themselves.
