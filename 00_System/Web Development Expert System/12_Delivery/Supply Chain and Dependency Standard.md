# Supply Chain and Dependency Standard

## Default
- approved sources
- lockfile
- clean deterministic CI install
- least-privilege CI tokens
- vulnerability ownership
- unused dependency removal
- secret scanning

## Higher assurance
Map desired source/build guarantees to current approved SLSA specification and preserve provenance/attestations where platform supports it.

A vulnerability scanner is input to risk management, not an automatic architecture decision.
