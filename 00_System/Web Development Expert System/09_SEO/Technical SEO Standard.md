# Technical SEO Standard

Only applies to intended public/indexable content.

## Required
- crawlability intentional
- correct status codes
- meaningful indexable content
- canonical rules
- titles/descriptions
- internal links
- sitemap for appropriate scale
- structured data only when truthful and supported
- monitor after URL/rendering migrations

## Security boundary
robots.txt and `noindex` are not authorization. Private data requires access control.
