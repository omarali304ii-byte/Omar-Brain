# Web Incident Checklist

- [ ] Declare severity and incident lead
- [ ] Protect users/data first
- [ ] Preserve evidence and timestamps
- [ ] Stop harmful rollout/traffic path safely
- [ ] Check recent deploy/config/dependency changes
- [ ] Communicate status and next update
- [ ] Recover with verified action
- [ ] Validate user/business outcomes
- [ ] Create postmortem and recurrence actions
- [ ] Create failure signature/regression test
