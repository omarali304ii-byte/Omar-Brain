# Arabic RTL and Internationalization Standard

Especially important for Omar/OVX products.

## Mandatory when Arabic/RTL applies
- correct `lang`
- correct `dir`
- logical DOM order
- mixed Arabic/Latin/number/SKU/URL fixtures
- locale-aware date/number/currency
- stable IDs separate from labels
- translated string expansion
- mirrored icons only when meaning warrants
- keyboard/focus remains logical

Test real Arabic content, not only lorem ipsum.
