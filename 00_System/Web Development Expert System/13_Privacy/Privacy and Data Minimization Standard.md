# Privacy and Data Minimization Standard

For personal data maintain:
- purpose
- source
- fields
- owner
- storage
- processors/vendors
- retention
- deletion
- user controls

## Rules
- collect minimum necessary
- do not repurpose silently
- minimize telemetry and analytics properties
- avoid sensitive browser storage
- define vendor exit/deletion
- test retention/deletion

Privacy is a product architecture concern, not a policy-page-only task.
