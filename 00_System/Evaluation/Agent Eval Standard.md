# Agent Eval Standard

## Score dimensions
- objective completion,
- acceptance criteria coverage,
- factual grounding,
- tool correctness,
- policy compliance,
- recovery from failure,
- evidence quality,
- unnecessary agent/tool/token use.

## Critical rule
A polished final answer cannot compensate for unverified external side effects or failed acceptance criteria.
