# Memory Write Eval Standard

Evaluate proposals and commits for:
- future usefulness,
- stability,
- provenance,
- canonical target correctness,
- duplicate creation,
- contradiction handling,
- confidence calibration,
- privacy compliance,
- over-generalization.

## Golden negative cases
The evaluator must reward rejecting:
- temporary task chatter,
- unsupported inference,
- duplicated project truth,
- secrets,
- one-off behavior promoted as universal law.
