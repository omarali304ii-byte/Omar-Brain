# Memory Consolidation Schedule

## After meaningful run
- write episode summary,
- extract candidate lessons/facts,
- create proposals only when future value exists.

## Daily
- process high-confidence pending proposals,
- flag failed runs and user corrections.

## Weekly
- deduplicate proposals,
- review contradictions,
- consolidate repeated episodes into candidate lessons,
- run retrieval evaluation set.

## Monthly
- revalidate volatile/active semantic memory,
- inspect repeated failure signatures,
- review procedural changes and eval regressions,
- archive cold queues without deleting evidence.

## Quarterly
- challenge architecture profiles,
- inspect whether agent roles are helping or creating overhead,
- review model/provider routing,
- run restore/reindex drill.
