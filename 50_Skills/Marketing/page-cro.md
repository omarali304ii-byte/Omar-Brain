# Page CRO

## Purpose

Improve marketing-page conversion by analyzing value clarity, message match, CTA hierarchy, scannability, trust, objections, and friction.

## When to activate

- cro
- conversion rate optimization
- landing page not converting
- improve conversions
- bounce rate
- homepage feedback
- pricing page conversion

## Inputs required

- Page/URL or artifact
- Primary conversion goal
- Traffic source
- Current conversion evidence
- Customer/VOC context

## Workflow

1. Identify page type, primary goal, and traffic/message context.
2. Test 5-second value proposition clarity.
3. Review headline/message match.
4. Review primary CTA visibility, value, hierarchy, and repetition.
5. Review visual hierarchy and mobile scanning.
6. Review trust/social proof near claims and decisions.
7. Map objections and missing proof.
8. Find friction in forms, navigation, performance, and next steps.
9. Separate quick wins from high-impact changes and experiments.

## Outputs

- Prioritized CRO audit
- Quick wins
- High-impact changes
- Test hypotheses
- Copy alternatives

## Quality gates

- [ ] No guaranteed uplift claims without experiment evidence
- [ ] Recommendations tied to observed page/user evidence
- [ ] One primary conversion goal made explicit
- [ ] Tests separated from assumed facts

## Road signs

- When **customer language** dominates → go to **Customer Research**.
- When **pricing page** dominates → go to **Pricing Strategy**.
- When **performance friction** dominates → go to **Performance Optimization**.
