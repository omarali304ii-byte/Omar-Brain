# Copywriting

## Purpose

Write clear, persuasive marketing copy grounded in audience problems, desired outcomes, proof, and one primary action.

## When to activate

- write website copy
- marketing copy
- homepage copy
- landing page copy
- headline
- cta copy
- hero section
- product page copy
- rewrite page copy

## Inputs required

- Page type and one primary conversion goal
- Target audience and problem
- Offer and differentiation
- Available proof and objections
- Traffic/source context

## Workflow

1. Load product/brand/customer context before drafting
2. Define the one reader, one problem, one promise, and one action
3. Build message hierarchy: headline → subheadline → proof → benefits → objections → CTA
4. Use customer language, specificity, active voice, and honest proof
5. Draft section by section; keep one idea per section
6. Run clarity, proof, specificity, and CTA checks
7. Hand off existing draft polish to Copy Editing and structural conversion issues to Page CRO

## Outputs

- Sectioned page copy
- Headline/CTA alternatives
- Proof gaps and assumptions
- Optional meta title/description

## Quality gates

- [ ] Primary action is unambiguous
- [ ] Claims are supported or clearly softened
- [ ] Copy uses customer language rather than internal jargon
- [ ] No fabricated proof, urgency, testimonials, or statistics
