# Onboarding CRO

## Purpose

Improve post-signup activation by shortening the path to a meaningful user outcome instead of maximizing completed tutorial steps.

## When to activate

- onboarding cro
- user activation
- product onboarding
- aha moment
- activation rate
- new user flow

## Inputs required

- Activation definition
- User segments
- Current onboarding flow
- Behavior data
- Product constraints

## Workflow

1. Define measurable activation and time-to-value
2. Map required versus optional setup
3. Find drop-offs and dead ends
4. Personalize only where evidence justifies it
5. Coordinate in-product and email onboarding
6. Design recovery paths for stalled users
7. Measure activation, time-to-value, retention correlation

## Outputs

- Activation map
- Prioritized onboarding changes
- Recovery flows
- Measurement plan

## Quality gates

- [ ] Activation is behavior/outcome based
- [ ] No vanity completion metric substitutes for value
- [ ] Recovery path exists
- [ ] Changes are instrumented
