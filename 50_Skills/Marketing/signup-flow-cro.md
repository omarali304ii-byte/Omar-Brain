# Signup Flow CRO

## Purpose

Reduce signup friction while preserving trust, security, required data, and the user’s understanding of what happens next.

## When to activate

- signup cro
- registration flow
- signup conversion
- registration friction
- account creation flow

## Inputs required

- Flow steps
- Traffic/source
- Required fields
- Drop-off data
- Auth constraints

## Workflow

1. Map every step and required decision
2. Separate truly required data from nice-to-have data
3. Inspect message match and expectation setting
4. Reduce cognitive load and uncertainty
5. Check errors, password rules, verification, mobile, accessibility, and trust
6. Instrument step-level conversion
7. Test changes instead of removing safeguards blindly

## Outputs

- Friction map
- Prioritized changes
- Experiment plan
- Tracking requirements

## Quality gates

- [ ] Security controls are not removed for conversion
- [ ] Step-level data exists or is requested
- [ ] Mobile/error states reviewed
- [ ] Primary hypothesis is testable
