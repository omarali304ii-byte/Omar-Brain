# Copy Editing

## Purpose

Improve existing marketing copy through focused editing passes without silently changing the core message or brand voice.

## When to activate

- edit this copy
- review my copy
- proofread marketing copy
- polish this
- too wordy
- tighten copy
- content audit
- refresh this page

## Inputs required

- Existing copy
- Original objective
- Audience and desired action
- Brand voice/context
- Known claims and proof

## Workflow

1. Preserve original intent unless a conflict is explicitly flagged
2. Run sequential sweeps: clarity, voice/tone, so-what benefit, proof, specificity, emotion, risk/friction
3. After each sweep, re-check earlier dimensions for regressions
4. Mark unsupported claims rather than inventing evidence
5. For high-stakes copy, run an independent critic/panel pass
6. Return changed copy plus material rationale

## Outputs

- Polished copy
- Change rationale
- Unsupported-claim list
- Remaining conversion risks

## Quality gates

- [ ] Core message preserved unless change is explicit
- [ ] No unsupported claim strengthened
- [ ] Voice stays consistent
- [ ] Every material edit has a reason
