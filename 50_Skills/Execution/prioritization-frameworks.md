# Prioritization Frameworks

## Purpose

Choose and apply a prioritization method transparently, exposing assumptions instead of hiding decisions behind a score.

## When to activate

- prioritize features
- prioritization framework
- rice score
- moscow
- what should we build first
- rank backlog

## Inputs required

- Decision objective
- Candidate items
- Evidence
- Constraints
- Capacity

## Workflow

1. Clarify what optimization target matters
2. Choose method fit: RICE, WSJF, impact/effort, MoSCoW, cost of delay, or custom
3. Define scoring scales before scoring
4. Score with evidence and uncertainty
5. Run sensitivity analysis on uncertain inputs
6. Document overrides and strategic constraints
7. Revisit when evidence changes

## Outputs

- Ranked options
- Score model
- Assumptions
- Sensitivity/override notes

## Quality gates

- [ ] Framework matches decision type
- [ ] Scores have evidence or uncertainty
- [ ] Output is not treated as objective truth
- [ ] Overrides are documented
