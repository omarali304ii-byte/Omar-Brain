# Stakeholder Map

## Purpose

Map decision rights, influence, impact, communication needs, and unresolved conflicts for a project or change.

## When to activate

- stakeholder map
- map stakeholders
- decision maker
- project stakeholders
- raci

## Inputs required

- Initiative
- Known people/roles
- Decision scope
- Risks
- Communication constraints

## Workflow

1. Identify affected and decision-making roles
2. Map influence, impact, interest, and decision rights
3. Record incentives and likely concerns without mind-reading
4. Define communication cadence and evidence needs
5. Escalate unresolved decision conflicts
6. Update as project changes

## Outputs

- Stakeholder map
- Decision-rights map
- Communication plan
- Conflict list

## Quality gates

- [ ] Decision owner is explicit
- [ ] Assumptions about people are labeled
- [ ] High-impact low-voice stakeholders are considered
- [ ] Conflicts have escalation path
