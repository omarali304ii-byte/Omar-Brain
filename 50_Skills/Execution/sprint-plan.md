# Sprint Plan

## Purpose

Create a capacity-aware execution plan from ready work, dependencies, risks, and definition-of-done evidence.

## When to activate

- sprint plan
- plan sprint
- iteration planning
- sprint backlog

## Inputs required

- Prioritized ready work
- Capacity
- Dependencies
- Risks
- Definition of done

## Workflow

1. Filter out unready work
2. Map dependencies and critical path
3. Estimate capacity with buffer for uncertainty
4. Select one sprint objective
5. Sequence work to reduce blocked time
6. Define verification per item
7. Track spillover cause rather than normalizing it

## Outputs

- Sprint objective
- Committed work
- Dependency map
- Verification plan
- Risks/buffer

## Quality gates

- [ ] Work is ready before commitment
- [ ] Capacity is explicit
- [ ] Dependencies have owners
- [ ] Every item has completion evidence
