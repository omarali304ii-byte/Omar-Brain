# Skill Distillation

## Purpose

Convert repeated evidence-backed workflows into reusable skill packages without silently overwriting prior knowledge.

## When to activate

- turn workflow into skill
- repeated task
- distill skill
- create reusable skill
- learn from project

## Inputs required

- Multiple task/project episodes
- Evidence of repeated pattern
- Existing skill registry
- Failure and exception cases

## Workflow

1. Inventory repeated episodes and outcomes.
2. Extract invariant steps separately from project-specific details.
3. Identify activation triggers, required inputs, outputs, stop conditions, failures, and verification.
4. Check for existing overlapping skill.
5. Merge additively or create a candidate/conflict record.
6. Register provenance and maturity.
7. Test the distilled skill on a fresh case before promotion.

## Outputs

- Candidate skill
- Coverage/provenance record
- Conflict/overlap notes
- Promotion recommendation

## Quality gates

- [ ] One successful task is not enough for a proven reusable skill
- [ ] No silent overwrite
- [ ] Exceptions and failure modes preserved
- [ ] Promotion requires fresh-case evidence

## Road signs

- When **durable procedural memory** dominates → go to **Procedural Memory Standard**.
- When **promotion** dominates → go to **Lesson and Pattern Promotion Ladder**.
