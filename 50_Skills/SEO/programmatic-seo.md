# Programmatic SEO

## Purpose

Design scalable search pages only when unique intent, trustworthy data, quality controls, and indexation strategy justify scale.

## When to activate

- programmatic seo
- seo at scale
- template pages
- location pages
- directory seo
- generate seo pages

## Inputs required

- Search intent set
- Data source
- Template model
- Uniqueness plan
- Indexation rules
- Quality threshold

## Workflow

1. Validate recurring search intent and business value
2. Define data/entity model and page uniqueness
3. Design template with meaningful variable content
4. Set minimum-quality and noindex rules
5. Prevent combinatorial thin-page explosion
6. Create internal linking and sitemap strategy
7. Launch small cohort, measure indexation/quality, then scale

## Outputs

- Page model
- Template spec
- Quality/index rules
- Pilot and measurement plan

## Quality gates

- [ ] Every indexed page serves distinct intent
- [ ] Data provenance exists
- [ ] Thin/empty combinations are blocked
- [ ] Pilot precedes broad scale
