# SEO Audit

## Purpose

Audit search performance across crawlability, indexation, technical health, content intent, internal links, structured data, and measurement.

## When to activate

- seo audit
- technical seo
- site seo check
- search visibility audit
- why not ranking

## Inputs required

- Site/domain
- Target market/language
- Analytics/search data
- CMS/stack
- Business goals

## Workflow

1. Confirm target market and priority pages
2. Check crawl/index controls and canonicalization
3. Audit status codes, sitemaps, robots, rendering, performance, mobile
4. Assess page intent, duplication, internal linking, metadata, and content gaps
5. Review structured data validity
6. Prioritize findings by impact, confidence, effort, and dependencies
7. Define verification for each fix

## Outputs

- SEO findings register
- Priority roadmap
- Page-level issues
- Verification plan

## Quality gates

- [ ] No ranking guarantee
- [ ] Technical and content issues are separated
- [ ] Findings have evidence
- [ ] Fixes include verification
