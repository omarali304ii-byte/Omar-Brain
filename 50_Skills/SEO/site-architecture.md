# SEO Site Architecture

## Purpose

Design crawlable, understandable information architecture around user intent, entity/topic relationships, internal links, and scalable URL rules.

## When to activate

- site architecture
- seo architecture
- url structure
- information architecture
- internal linking strategy

## Inputs required

- Content inventory
- User/search intents
- Entities/topics
- Current URLs
- Business priorities

## Workflow

1. Map intents and entities
2. Group content by real relationships, not arbitrary folder depth
3. Define canonical URL patterns and ownership
4. Design navigation and contextual internal links
5. Prevent orphan/duplicate/thin page patterns
6. Plan redirects/migrations for changes
7. Validate crawl paths and indexation

## Outputs

- Architecture map
- URL rules
- Internal-link model
- Migration risks

## Quality gates

- [ ] Every important page has a discovery path
- [ ] URL rules are deterministic
- [ ] Duplicate intent is resolved
- [ ] Migration includes redirect plan
