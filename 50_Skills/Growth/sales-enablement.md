# Sales Enablement

## Purpose

Turn customer/market evidence into practical sales messaging, qualification, objection handling, and proof assets.

## When to activate

- sales enablement
- sales playbook
- objection handling
- battlecard
- sales deck
- qualify leads

## Inputs required

- ICP/JTBD
- Sales motion
- Objections
- Competitors
- Proof
- Pipeline stage

## Workflow

1. Define buyer/problem/trigger per segment
2. Map discovery questions to qualification decisions
3. Create value narrative and proof
4. Document competitor/alternative positioning honestly
5. Build objection responses with evidence
6. Create stage-specific assets
7. Measure usage and win/loss feedback

## Outputs

- Sales playbook
- Discovery questions
- Objection bank
- Proof map
- Asset gaps

## Quality gates

- [ ] Claims are supported
- [ ] Qualification avoids demographic fiction
- [ ] Competitor claims are current
- [ ] Assets map to stages
