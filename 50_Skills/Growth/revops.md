# Revenue Operations

## Purpose

Align marketing, sales, onboarding, and customer success around consistent lifecycle definitions, ownership, data, and handoffs.

## When to activate

- revops
- revenue operations
- lead lifecycle
- sales pipeline process
- marketing sales handoff
- crm process

## Inputs required

- Lifecycle stages
- Teams/owners
- CRM/data model
- SLAs
- Revenue goals
- Current handoff failures

## Workflow

1. Map actual lifecycle from lead to expansion/churn
2. Define stage entry/exit criteria
3. Assign system of record and owner
4. Design handoff SLAs and exception paths
5. Standardize required fields and attribution rules
6. Create dashboard and data-quality checks
7. Review leakage and cycle time regularly

## Outputs

- Lifecycle model
- Ownership/SLA map
- Data rules
- Dashboard requirements
- Leakage backlog

## Quality gates

- [ ] Stages have objective criteria
- [ ] One source of truth per field
- [ ] Handoffs have owners
- [ ] Dashboard metrics map to actions
