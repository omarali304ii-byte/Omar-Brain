# Free Tool Strategy

## Purpose

Design a genuinely useful free tool that attracts the right audience, creates value before capture, and connects naturally to the paid product.

## When to activate

- free tool strategy
- lead magnet tool
- free calculator
- free generator
- engineering as marketing

## Inputs required

- Target audience
- Recurring job/problem
- Product value path
- Distribution channel
- Build/maintenance cost

## Workflow

1. Find a frequent narrow job with search/share potential
2. Ensure standalone value
3. Define minimal input and immediate output
4. Connect paid product only where naturally relevant
5. Model acquisition and maintenance economics
6. Launch small and instrument qualified usage
7. Improve from real use

## Outputs

- Tool concept
- Value/transition map
- MVP scope
- Distribution plan
- Metrics

## Quality gates

- [ ] Tool provides real value without payment
- [ ] Audience fit is explicit
- [ ] Paid transition is not bait-and-switch
- [ ] Maintenance cost considered
