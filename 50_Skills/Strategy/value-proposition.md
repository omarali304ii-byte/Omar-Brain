# Value Proposition

## Purpose

Design a segment-specific value proposition using Who → Why → What Before → How → What After → Alternatives.

## When to activate

- value proposition
- value prop
- customer value
- jtbd value
- why choose us
- positioning statement

## Inputs required

- Target segment
- Customer problem/JTBD evidence
- Current alternatives
- Product capabilities
- Desired outcomes

## Workflow

1. Define one segment per pass.
2. State the customer job/problem and evidence.
3. Describe current before-state and friction.
4. Connect specific capabilities to how value is delivered.
5. Describe observable after-state.
6. Name real alternatives including do-nothing/DIY.
7. Write concise value and positioning statements.
8. Test language with customer evidence.

## Outputs

- 6-part value proposition
- Concise value statement
- Positioning statement
- Alternative comparison
- Evidence gaps

## Quality gates

- [ ] No generic “for everyone” proposition
- [ ] Capabilities must connect to customer outcome
- [ ] Alternatives explicit
- [ ] Unvalidated claims labeled
