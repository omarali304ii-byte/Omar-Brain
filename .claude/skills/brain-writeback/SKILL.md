# Brain Writeback

Use after meaningful verified work, not after every small edit.

## Procedure
1. Identify what changed in reality.
2. Separate:
   - verified current truth
   - evidence/run record
   - episodic history
   - reusable learning candidate
3. Search exact title/IDs/aliases and semantic near-duplicates.
4. Read canonical target before edit.
5. Choose one: update, create, merge, link-only, inbox proposal, discard-with-reason.
6. Preserve source, confidence, revision, verification scope, contradictions, and uncertainty.
7. Update project current state/queue only for verified changes.
8. Reusable lesson stays candidate-first unless promotion evidence exists.
9. Never silently overwrite human decisions or conflicting evidence.
10. Validate affected brain control files when applicable.

Do not use Claude auto memory as a second brain.
